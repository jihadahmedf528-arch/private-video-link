# Private Video Link

Telegram Mini App + Bot + Firebase Realtime Database + Admin Panel.

## Local/Render
Build command:
npm install

Start command:
npm start

## Environment variables
See `.env.example`.

## Pages
- `/` — user Mini App
- `/admin.html` — admin panel
- `/health` — health check

## Firebase paths
- `videos/{videoId}`
- `settings/ads`

Only use lawful, permitted video content and official advertising SDKs.
